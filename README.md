#  Shopping Cart Application

A simple desktop shopping cart application built with Python and Tkinter. This project features a GUI for managing cart items and unit tests to ensure the core logic works correctly. Developed as part of a Quality Assurance course to demonstrate modular design, CRUD operations, and testing.



# Features

- Add, update, and remove items in the cart  
- View cart contents and total price  
- Clear cart on checkout  
- GUI built with Tkinter  
- Unit tests using Python's unittest framework



# Technologies

- Python 3.x  
- Tkinter (built-in GUI toolkit)  
- unittest (built-in testing module)
